# Mio 2.4.4 简体中文汉化

**汉化作者：9407-guangchenyi**

基于 [open-zio](https://github.com/minecraftlover74/open-zio) 的 Minecraft 1.21.11 Fabric 客户端模组汉化版本。

---

## 汉化内容

| 类别 | 数量 |
|---|---|
| 面板分类 | 8 |
| 模块显示名 | 202 |
| 设置项名称 | 926 |
| 模块描述 | 176 |

| Totem | 图腾 |

## 技术实现

汉化不是简单替换字符串，而是新增了一层**显示名翻译层**，保证不影响内部逻辑：

1. **新增 `DisplayNames` 类**  
   负责把内部名（如 `Sprint`）翻译成显示名（如 `自动疾跑`），查不到时回退英文。

2. **语言文件**  
   `assets/zio/lang/zh_cn.ini` 使用分节语法管理 1312 条翻译。

3. **不修改内部标识**  
   模块名同时是配置键、命令别名和搜索关键词，因此只在**渲染时**翻译，配置文件和命令系统保持英文，不会导致存档失效。

4. **字体补字**  
   原版字库只有 2761 个常用汉字，缺少「戮」「氛」「隧」「骼」等字。  
   新增 `CHINESE_EXTRA` 字符范围补齐，避免出现「杀戮光环」显示成「杀光环」的问题。

5. **动态面板宽度**  
   中文比英文宽，面板宽度改为按内容自动测量，解决文字被截断的问题。

## 使用方法

1. 安装 **Minecraft 1.21.11 + Fabric Loader**
2. 安装 **Fabric API**
3. 把 `Mio-2.4.4.jar` 放进 `mods` 文件夹
4. 启动游戏，按 **右 Shift** 打开菜单
5. 进入 **客户端** 面板 → `UI` → `Language` → 选择 **Chinese**

## 已知说明

- 未翻译的模块会显示英文原名（可正常使用）
- 命令补全仍使用英文（因为命令解析依赖英文名）
- 部分模块的 info 后缀（如 `TO:NEVER_LOCK`）为代码动态生成，未汉化
